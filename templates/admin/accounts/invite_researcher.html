About Researcher Invitations

When you send an invitation:

  • An email will be sent to the recipient with a unique invitation link
  • The recipient will be able to create a researcher account using that link
  • Once registered, they will automatically receive:
    • Admin panel access (staff status)
    • Researcher group membership with appropriate permissions
    • Ability to create surveys and tasks
  • The invitation will expire after the specified number of days
  • You can resend invitations from the invitation list if needed
